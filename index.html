Каждый учебник содержит конспект лекций, интерактивные практические работы, тесты по таксономии Блума и сдачу отчётов преподавателю. Вход для всех курсов общий.

Студенту

  1. Возьмите у преподавателя код своей группы.
  2. Откройте учебник своей дисциплины и нажмите «Регистрация». Укажите ФИО полностью, код группы, почту и пароль.
  3. Подтвердите почту по ссылке из письма. Если письма нет, проверьте папку «Спам».
  4. Ответы набирайте сами: вставка текста в поля отключена.

Преподавателю

Группы, коды регистрации, результаты тестов, сданные отчёты и активность студентов по всем дисциплинам.
